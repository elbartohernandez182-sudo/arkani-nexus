MANUAL DE INSTRUCCIONES DE APRENDIZAJE AUTONOMO — ARKANI NEXUS
Protocolo Wardenclyffe v4.0 — Como aprender, donde buscar, que priorizar

[INSTRUCCION 01: CUANDO EL USUARIO DICE "APRENDE INTERNET: TEMA"]
Cuando recibes el comando "aprende internet: [tema]", debes:
1. Identificar el tema central (ejemplo: "python decoradores")
2. Buscar en estas fuentes en orden de prioridad:
   PRIORIDAD 1 — Documentacion oficial:
     - docs.python.org para Python
     - flask.palletsprojects.com para Flask
     - developer.mozilla.org para web
     - pytorch.org/docs para machine learning
   PRIORIDAD 2 — Tutoriales de alta calidad:
     - realpython.com
     - python-guide.org
   PRIORIDAD 3 — Enciclopedia:
     - es.wikipedia.org (espanol primero)
     - en.wikipedia.org (ingles si no hay en espanol)
3. Descargar el contenido textual (no imagenes, no PDFs binarios)
4. Guardar en memoria_permanente/ con nombre descriptivo
5. Responder: "Descargado [N] fuentes sobre [tema]. Se digeriran esta noche."
6. NO intentar procesar con Ollama en tiempo real (causa timeout)

[INSTRUCCION 02: CUANDO EL USUARIO DICE "CREA: PROGRAMA"]
Cuando recibes el comando "crea: [descripcion]", debes:
1. Generar codigo Python funcional y completo
2. Guardar en autogen/ con nombre descriptivo
3. El codigo debe:
   - Tener comentarios en espanol
   - Incluir if __name__ == '__main__':
   - Ser ejecutable directamente con python3
   - Usar solo stdlib o dependencias comunes (requests, flask, json, os)
4. Mostrar preview de las primeras 20 lineas
5. Dar el comando exacto para ejecutarlo

Para temas medicos y radiologicos, buscar en:
   PRIORIDAD 1 — Guias oficiales:
     - radiopaedia.org (atlas radiologico mundial)

     - fleischner.org (guias nodulo pulmonar)
   PRIORIDAD 2 — Educacion medica:

   PRIORIDAD 3 — Wikipedia medica:

[INSTRUCCION 04: COMO ORGANIZAR EL CONOCIMIENTO APRENDIDO]
Todo conocimiento aprendido se organiza en tres niveles:
   NIVEL 1 — Memoria permanente (memoria_permanente/):
     Archivos .txt con contenido descargado
     Nombre: tema_fuente_fecha.txt
     Se digieren de noche por el daemon

   NIVEL 2 — Dataset fractal (arkani_fractal_dataset_v2.json):
     Pares instruccion/output en formato NEXUS-LANG
     Alimenta el entrenamiento de arkani-fractal
     Crece automaticamente con digestion_fractal.py

   NIVEL 3 — Hipocampo (hipocampo.bin):
     Neuronas binarias de 16 bytes
     Una neurona EVOLVE por cada 5 conceptos aprendidos
     Memoria a largo plazo inviolable
